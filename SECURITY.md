# Security policy

Agent Process is a specification. Security issues here are usually in the protocol itself: a rule that lets an agent act where only a person should, a way to reuse or forge a claim, evidence that can be swapped after acceptance, or a path to read data across runs or organizations.

## Reporting

Report suspected vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/agentprocess/agentprocess/security/advisories/new). Please do not open a public issue or discussion. Include the section of the specification, a trace or `PROCESS.md` that shows the problem, and its impact.

You will receive an acknowledgement, and fixes are recorded in `spec/revisions.md` once disclosed.

For a vulnerability in a particular server implementation, report it to that implementation's maintainers.
